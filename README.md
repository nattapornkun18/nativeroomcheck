# เช็คห้อง · Hotel Room Check

หน้าเว็บเดียวสำหรับเช็กห้องทุกเรื่อง — **เลือกหมวด → เลือกห้อง → เช็ก**
ตอนนี้มี **ม่าน** กับ **ซิลิโคนขอบอ่าง** เพิ่มหมวดใหม่ทีหลังได้โดยไม่ต้องทำเว็บใหม่

ทุกหมวดใช้ Google Sheet เดียวกัน Apps Script ตัวเดียวกัน และลิงก์ Web App เส้นเดียวกัน
แต่ละหมวดแยกเก็บเป็นแท็บของตัวเองในชีต คอลัมน์จึงไม่ปนกัน

## ไฟล์ในรีโป

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด เปิดตรง ๆ หรือวางบน GitHub Pages ก็ได้ |
| `Code.gs` | Apps Script ฝั่งชีต — รับข้อมูล เขียนลงแท็บ และแจ้งเตือนเข้า LINE |
| `SETUP.md` | วิธีติดตั้ง ตั้งค่าแจ้งเตือน และวิธีเพิ่มหมวดใหม่ |

## จุดที่ตั้งใจให้เป็นแบบนี้

- **กดบันทึกครั้งเดียว = ไลน์เด้งครั้งเดียว** ต่อให้รอบนั้นอัปเดตทั้งม่านทั้งซิลิโคน
  ก็รวมอยู่ในข้อความเดียว กดสองรอบก็เด้งสองครั้ง แก้ไขทีหลังก็แจ้งอีกครั้ง
  พร้อมบอกว่าช่องไหนเปลี่ยนจากอะไรเป็นอะไร
- **ทุกข้อความมีหัวข้อ** บอกว่าอัปเดตเรื่องอะไร (`🪟 ม่าน` / `🧴 ซิลิโคนขอบอ่าง`)
  และปิดท้ายด้วยชื่อผู้ตรวจกับวันที่แบบไทย วัน/เดือน/ปี
- **ในห้องเดียวสลับหมวดได้** ของที่กรอกค้างไว้ไม่หาย แท็บไหนแก้ค้างอยู่จะมีจุดสีทองบอก
- **เน็ตหลุดไม่เสียงาน** เก็บไว้ในเครื่องก่อนแล้วส่งให้เองเมื่อกลับมาออนไลน์
  โดยยังนับเป็นหนึ่งข้อความต่อการกดหนึ่งครั้งเหมือนเดิม
