# เช็คห้อง · Hotel Room Check

หน้าเว็บเดียวสำหรับเช็กห้องทุกเรื่อง — **เลือกหมวด → เลือกห้อง → เช็ก***
ตอนนี้มี 6 หมวด เพิ่มหมวดใหม่ทีหลังได้โดยไม่ต้องทำเว็บใหม่

| หมวด | เช็กอะไร |
|---|---|
| 🪟 ม่าน | ปิดสุดไหม (ห่างเกิน 10 ซม. = ไม่ผ่าน) เปิดสุดไหม แสงลอด สวิตช์ กระตุก **ดึงมือตอนไฟดับ** WD40 เสียง เดินรางลื่นไหม งานติดตั้ง ชายม่าน ลอนม่าน — จุดที่ไม่ผ่านแยกให้เองว่า **ทีมโรงแรม** หรือ **ทีมช่างม่าน** มาแก้ |
| 🧴 ซิลิโคนขอบอ่าง | ขอบเขตที่ยิง สี ระยะขอบ ตัดขอบ ฟองอากาศ กินผนัง |
| 🌡️ น้ำร้อน & แอร์ | เปิดน้ำร้อนกี่วิถึงร้อน · กี่นาทีห้องถึงเย็นถึงอุณหภูมิที่ตั้ง |
| 🚪 แสงรอบประตู | แตะผังประตูว่าแสงลอดตรงไหน ลงชีตเป็นข้อความ ไม่เก็บรูป |
| 🪵 คิ้วบัวใต้ซิงค์ | บัวซ้าย·กลาง·ขวา ติดครบไหม ขอบสุดขาไม้ไหม มีช่องรูผนัง–พื้นไหม |
| 🚿 หลืบห้องน้ำ | ร่อง shadow gap กระเบื้องสุดขอบไหม · ในร่องทาสีไหม สีอะไร |

หมวดคิ้วบัวใต้ซิงค์ไม่ตรวจห้อง `01` กับ `12` ของทุกชั้น (ห้องมุมไม่มีบัว)
ส่วนห้อง `02` กับ `11` ตามแบบไม่มีบัว หน้าเว็บจะซ่อนหัวข้อบัวให้ เหลือแค่ช่องรูสามจุด

**เกณฑ์รับงานสองหมวดนี้**

| หมวด | ผ่านเมื่อ |
|---|---|
| 🪵 คิ้วบัวใต้ซิงค์ | ติดบัวครบทุกช่วง ขอบเดินไปสุดขาไม้ และไม่มีช่องรูผนัง–พื้นสักจุด |
| 🚿 หลืบห้องน้ำ | ปูกระเบื้องสุดขอบร่อง shadow gap และในร่องไม่ทาสี |

ห้องที่บันทึกไว้ก่อนเปลี่ยนเกณฑ์ไม่ต้องเดินไล่กรอกใหม่ — เปิดชีตแล้วสั่ง
**เช็คห้อง → ตัดเกรดใหม่จากข้อมูลเดิม** ครั้งเดียว (ดู SETUP.md หัวข้อ “หมวดหลืบห้องน้ำ”)

**รอบตามแก้ — อนุโลม / รอแก้ไข / แก้ไขแล้ว**

ตรวจไปแล้วรอบหนึ่ง พอมาดูของจริงหรือดูรูปอีกที บางจุดผู้ตรวจอนุโลมให้ผ่านได้
ทุกหมวดจึงมีช่อง **สถานะแก้ไข** ที่โผล่ให้กดเฉพาะตอนที่รอบนั้นมีจุดไม่ผ่าน

| สถานะ | ผลกับห้องนั้น |
|---|---|
| รอแก้ไข (ค่าตั้งต้น) | ยังค้าง — นับเป็น **ไม่ผ่าน** เหลืองหรือแดงตามความหนักเบา |
| อนุโลม | ผู้ตรวจยอมให้ผ่าน — ห้องนี้ **ปิดจบ** (สีน้ำเงิน) ช่องผลตรวจลงว่า ผ่าน |
| แก้ไขแล้ว | ช่างแก้แล้ว ตรวจซ้ำเรียบร้อย — ห้องนี้ **ปิดจบ** เหมือนกัน |

ค่าที่กรอกไว้ตอนเจอข้อบกพร่องยังอยู่ครบ ไม่ถูกลบ — ตามย้อนได้เสมอว่าเดิมเสียตรงไหน
หน้าสรุปแยกให้สองตาราง **ห้องที่ยังรอแก้ไข** กับ **ปิดจบแล้ว (อนุโลม/แก้ไขแล้ว)**
กดอนุโลมในชีตเองก็ได้ ห้องนั้นถือว่าปิดจบทันที

ทุกหมวดใช้ Google Sheet เดียวกัน Apps Script ตัวเดียวกัน และลิงก์ Web App เส้นเดียวกัน
แต่ละหมวดแยกเก็บเป็นแท็บของตัวเองในชีต คอลัมน์จึงไม่ปนกัน
แท็บใช้ชื่ออังกฤษ — `Summary` · `Curtain & Sheer` · `Silicone` · `HW and A/C` · `Door` · `Molding` · `Bathroom`

**เว็บใช้งานจริง** https://nattapornkun18.github.io/nativeroomcheck/
(repo `curtainandsheer` เหลือแค่หน้าเด้งมาที่นี่ ไม่มีสำเนาโค้ดแล้ว)

## จุดที่ตั้งใจให้เป็นแบบนี้

- **กดบันทึกครั้งเดียว = ไลน์เด้งครั้งเดียว** ต่อให้รอบนั้นอัปเดตทั้งม่านทั้งซิลิโคน
  ก็รวมอยู่ในข้อความเดียว กดสองรอบก็เด้งสองครั้ง แก้ไขทีหลังก็แจ้งอีกครั้ง
  พร้อมบอกว่าช่องไหนเปลี่ยนจากอะไรเป็นอะไร
- **ทุกข้อความมีหัวข้อ** บอกว่าอัปเดตเรื่องอะไร (`🪟 ม่าน` / `🧴 ซิลิโคนขอบอ่าง`)
  และปิดท้ายด้วยชื่อผู้ตรวจกับวันที่แบบไทย วัน/เดือน/ปี
- **เลือกห้องจากผังชั้น** ปุ่มห้องวางตามตำแหน่งจริงในแปลน ไม่ได้เรียงเป็นตาราง 1–12
  ยืนอยู่ตรงไหนก็กดตรงนั้น ไม่ต้องแปลงเลขห้องในหัว
- **ในห้องเดียวสลับหมวดได้** ของที่กรอกค้างไว้ไม่หาย แท็บไหนแก้ค้างอยู่จะมีจุดสีทองบอก
- **เน็ตหลุดไม่เสียงาน** เก็บไว้ในเครื่องก่อนแล้วส่งให้เองเมื่อกลับมาออนไลน์
  โดยยังนับเป็นหนึ่งข้อความต่อการกดหนึ่งครั้งเหมือนเดิม

## เวลาชิปขึ้นว่า “ต่อไม่ติด”

ชิปมุมขวาบนบอกสถานะการคุยกับชีต แตะที่ชิปจะเห็นสาเหตุล่าสุดในกล่องตั้งค่า

- **สะดุดแวบเดียว** — แอปลองซ้ำให้เอง 3 ครั้ง แล้วลองใหม่อีกเป็นระยะ (4 วิ → 8 → 15 → 30 → 60)
  ระหว่างนั้นชิปยังเป็น “กำลังซิงก์” ไม่แดง เน็ตกลับมาเมื่อไหร่ก็เขียวเอง ไม่ต้องรีเฟรช
- **ออฟไลน์** — ที่กรอกไว้เก็บในเครื่อง ส่งให้เองเมื่อกลับมาออนไลน์
- **“Google ตอบกลับเป็นหน้าเว็บ ไม่ใช่ข้อมูล”** — ตัว deploy ไม่ได้เปิดให้คนนอกเข้า
  ไปที่ Apps Script › Deploy › Manage deployments › ✏️ › **Who has access = Anyone** แล้วกด Deploy
- **“unauthorized”** — `TOKEN` ใน `Code.gs` ไม่ตรงกับรหัสที่ใส่ในเครื่อง
- **แก้ `Code.gs` แล้วต้องกด Deploy ใหม่ทุกครั้ง** ไม่งั้น URL เดิมยังวิ่งโค้ดเก่าอยู่

**ห้องละแถวเดียวตลอด** ตรวจซ้ำห้องเดิมกี่รอบก็วางทับแถวเดิม ชีตไม่มีแถวซ้ำสะสม
คอลัมน์ที่หน้าเว็บไม่ได้ถามไม่ถูกล้าง และไลน์ยังบอกได้ว่าเปลี่ยนจากอะไรเป็นอะไร
ชีตที่มีแถวซ้ำค้างอยู่ ยุบได้ที่เมนู **เช็คห้อง → ยุบแถวซ้ำ ให้เหลือห้องละแถว**

ส่งซ้ำตอนเน็ตสะดุดก็ไม่ทำให้ได้แถวซ้ำ ทุกครั้งที่กดบันทึกจะติดรหัสก้อน (`reqId`) ไปด้วย
ฝั่งชีตจำไว้ 6 ชั่วโมง ก้อนเดิมที่ส่งมาใหม่จะได้คำตอบเดิมกลับไป ไม่เขียนซ้ำและไม่ยิงไลน์ซ้ำ

## หน้าสรุป

- **ในชีต** แท็บ `Summary` — อัปเดตเองทุกครั้งที่มีคนกดบันทึก
  ภาพรวมรายหมวด · ความคืบหน้ารายชั้น · ห้องที่ยังรอแก้ไข · ห้องที่ปิดจบแล้ว (อนุโลม/แก้ไขแล้ว)
